App Android nativa + Backend distribuido

Proyecto de ingeniería de software orientado al seguimiento de fútbol europeo, predicciones por puntos y comunicación entre usuarios. La solución separa la aplicación cliente de la lógica de negocio mediante una API REST propia y canales de eventos en tiempo real.

Arquitectura cliente-servidor MVVM + Clean Architecture SQL + NoSQL
Sistema modular · API REST · WebSockets

01 · Capa cliente

Aplicación Android

La aplicación nativa está construida en Kotlin con Jetpack Compose. La interfaz se divide en componentes declarativos y consume estados expuestos por ViewModels, evitando acoplar la UI a la infraestructura de red.

Presentación declarativa

Jetpack Compose, Navigation y componentes reutilizables para representar pantallas de partidos, grupos, perfiles y estadísticas.

Composable → ViewModel → UiState

Estado y ciclo de vida

MVVM/Clean Architecture separa presentación, casos de uso y repositorios. LiveData y DataStore mantienen preferencias y estados observables.

UI ← observable state

Cliente HTTP

Retrofit 2 y Gson tipan el contrato de la API. Coroutines ejecutan operaciones asíncronas y permiten gestionar loading, success y error.

Retrofit + Gson + Coroutines

Eventos en tiempo real

Pusher WebSockets entrega mensajes de chat, reacciones y cambios de encuestas sin polling ni recarga de la vista.

Subscribe → Event → State
Usuario→Composable→ViewModel→Use case / Repository→Retrofit o Pusher

02 · Capa servidor

Backend y API REST

Laravel 12 centraliza la lógica de dominio y funciona como frontera entre Android y los proveedores externos. La API valida entradas, aplica autorización y devuelve recursos consistentes para el cliente.

AndroidRetrofit / Pusher
HTTPS · JSON
Laravel 12Controllers · Services · Policies
ORM / Events
PersistenciaPostgreSQL + MongoDB
ProveedoresFootball-Data.org · News API
Reverb / PusherWebSockets
SchedulerSincronización automática

Autenticación y autorización

Google OAuth, verificación de correo, soporte 2FA y control de permisos por rol.

Persistencia híbrida

PostgreSQL almacena usuarios, ligas, equipos, partidos, grupos y predicciones. MongoDB concentra logs, auditoría e incidencias.

Procesamiento programado

Laravel Scheduler sincroniza marcadores y valida predicciones al finalizar los partidos para calcular puntos y rankings.

Comunicación en tiempo real

Laravel Reverb y Pusher publican eventos de chat, typing indicators, reacciones y encuestas grupales.
